Cancelling Bookings

As an Account Manager, you can cancel your own bookings at any time. Cancelling a booking will remove it from the schedule and notify all relevant parties.

How to Cancel a Booking
  • Navigate to "My Bookings" from the main menu
  • Find the booking you want to cancel and click on it to open the Booking Details panel
  • Click the red "Cancel Booking" button at the bottom of the details panel
  • Enter a cancellation reason (required) - this helps managers understand why bookings are cancelled
  • Click "Confirm Cancellation" to proceed
Important: Cancelling Confirmed Bookings If you cancel a confirmed booking, the calendar event will be automatically deleted, and the assigned specialist, client, and managers will all receive notification emails. Please only cancel confirmed bookings when absolutely necessary.
What Gets Cancelled When you cancel a booking:
- The booking status changes to "Cancelled"
- Calendar events are deleted (if confirmed)
- Email notifications are sent to all parties
- The cancellation reason is logged for audit purposes
- The booking remains visible in your history (filtered by default)
Rescheduling Bookings

If your client's availability changes or you need to adjust the timing, you can request a reschedule. This submits new proposed time slots for manager approval.

How to Reschedule
  • Open the booking from "My Bookings"
  • In the Booking Details panel, click "Reschedule" in the footer actions
  • The reschedule dialog will show the current confirmed date/time for reference
  • Select up to 3 new proposed time slots using the date/time pickers (displayed vertically for easy selection)
  • Add an optional reschedule reason to explain why the change is needed
  • Click "Submit Reschedule Request"
Reschedule Workflow 1. Status Change: The booking status changes to "Rescheduling Required"
2. Manager Review: A manager reviews and selects from your new proposed slots
3. Calendar Update: The original calendar event is updated with the new date/time
4. Notification: All parties receive updated calendar invites and email notifications
5. Confirmed: Status returns to "Confirmed" once approved
Pro Tip: Provide Diverse Slots When rescheduling, try to propose time slots across different days or times to give managers more flexibility in finding an available specialist.
Demo Preparation Checklists

Checklists help ensure you're fully prepared before each demo or deployment session. They guide you through essential preparation steps so nothing is forgotten.

How to Use Checklists
  • Navigate to "Checklists" from the main navigation menu
  • Select the appropriate checklist type: Demo Preparation or Deployment Preparation
  • Work through each item, clicking the checkbox to mark items as complete
  • Your progress is automatically saved so you can return and continue later
  • View the progress indicator to see how many items remain
Verify client contact details and attendees
Review client's current software environment
Prepare demo environment with sample data
Test screen sharing and audio setup
Checklist Types Demo Checklists: Cover presentation setup, demo environment preparation, client research, and technical readiness checks.

Deployment Checklists: Include pre-deployment verification, environment requirements, data migration steps, and post-deployment validation tasks.

Administrators can customize checklists via Admin > Checklists to add, edit, or remove items as processes evolve.
Calendar View

The Calendar View provides a visual representation of all scheduled bookings, making it easy to see availability and plan ahead.

Calendar Features
  • Multiple Views: Switch between Month, Week, Day, and Agenda views using the toolbar buttons
  • Color-Coded Status: Bookings are color-coded by status - green for confirmed, yellow for pending, blue for rescheduling, red for cancelled
  • Premium Indicators: Premium client bookings are highlighted with a gold/amber border for easy identification
  • Click for Details: Click any booking in the calendar to open the full Booking Details panel
  • Navigation: Use the arrow buttons to move between months/weeks, or click "Today" to jump to the current date
  • Status Legend: A legend at the bottom explains the color coding for quick reference

Timeline View

The Timeline View shows bookings in a chronological list, grouped by date, perfect for reviewing upcoming appointments and recent activity.

Timeline Features
  • Chronological Order: Bookings are displayed in order from earliest to latest, grouped by date
  • Smart Date Labels: Dates show friendly labels like "Today", "Tomorrow", or "Yesterday" for quick reference
  • Date Grouping: Clear date headers separate bookings, showing the day of week and full date
  • Booking Cards: Each booking shows client name, booking type, time, status badge, and assigned specialist
  • Status Badges: Color-coded status badges help you quickly identify pending, confirmed, or rescheduled bookings
  • Quick Actions: Click any booking to open details where you can reschedule, clone, or cancel
Accessing Timeline View The Timeline View is available to all users directly from the "My Bookings" page. Click the "Timeline" button in the view toggle (next to Cards, List, and Calendar) to switch to timeline view. Your bookings will be displayed chronologically, filtered to show only your own bookings.
Calendar vs Timeline Use Calendar View when you need to see availability across weeks/months or find open slots. Use Timeline View when reviewing a sequence of upcoming bookings or checking what's scheduled for the near future.
