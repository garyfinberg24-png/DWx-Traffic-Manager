V6 Three-Level Hierarchy:

Level 1 - Underline Tabs: Section navigation (e.g., Project Scope | Functional Requirements | Technical Environment)
Level 2 - Section Accordions: Group related questions with icon, description, and completion status badge
Level 3 - Question Accordions: Each individual Q&A is collapsible. Shows question text, required/optional/answered badge. Expand to see the answer controls.

States shown above: Q1 in Project Scope is "Answered" (green badge, collapsed by default). Q2 is "open" (user is working on it). Q3 is collapsed with "Required" badge. In Deal Info, "Interest Level" shows the answered value right in the badge ("Warm").

Steps with 2+ sections (Client, Discovery): All 3 levels.
Steps with 1-2 groups (Deal Info, Schedule): Levels 2+3 only (no tabs).
Step 1 (Service): Card grid (no change). Step 6 (Review): Section accordions (all expanded).
Comparison
Side-by-Side Comparison
A summary of all 5 variations with pros, cons, and recommended use cases.
Variation Style Pros Cons Best For
V1
Underline Tabs		 Classic horizontal tabs with underline active indicator + Familiar pattern (Fluent UI native)
+ Clean, minimal
+ Easy to implement with TabList		 - Tab labels can crowd on narrow screens
- All questions visible in tab panel (may still scroll)		 Steps with 2-4 evenly-sized sections. Default choice for Discovery step.
V2
Pill Tabs + Accordions		 Rounded pill buttons for sections, accordion sub-groups within + Two levels of organization
+ Reduces visual overwhelm
+ Question counts in badges		 - More complex to implement
- Users must click twice (pill + accordion)
- May feel over-engineered for small sections		 Sections with 5+ questions that can be sub-grouped logically.
V3
Vertical Side Tabs		 Left sidebar with icons and badges, right content panel + Always-visible navigation
+ Room for icons + question counts
+ Professional look		 - Takes horizontal space (~220px sidebar)
- Sidebar adds complexity on mobile
- Less standard for forms		 Steps with 4+ sections. Settings-like UIs. Wide screens.
V4
Segmented + Cards		 iOS-style segmented control, questions wrapped in individual cards + Very clean, survey-like feel
+ Each question stands out
+ Numbered progress		 - More vertical space per question
- Cards can feel repetitive
- Segmented control less familiar in web		 Questionnaire-style discovery. Sections with varied question types.
V5
Full Accordion		 No tabs. All sections are expandable panels with status badges + Guided interview feel
+ Completion tracking built-in
+ No hidden content behind tabs
+ Progressive disclosure		 - Only one section open at a time
- Switching sections requires scrolling
- Less discoverable than tabs		 Linear/sequential discovery. When users should complete sections in order.
V6
Hybrid		 3 levels: V1 underline tabs → V5 section accordions → question-level mini-accordions for each Q&A + Best of all patterns
+ Tabs for section nav
+ Section accordions for grouping
+ Question accordions for focus
+ Completion badges at every level
+ Answered Qs collapse to one line
+ Scales to any question count		 - Most complex to build
- Three levels of nesting		 Discovery step with many questions per section. The recommended approach for rich questionnaires.

Recommendation

V6 (Underline Tabs + Accordions) is the recommended approach. It combines the familiar, clean section navigation of V1's underline tabs with V5's rich accordion panels for question grouping. This gives users two levels of organization: tabs to jump between sections quickly, and accordions to expand/collapse question groups within each section, with completion status badges to track progress.

Strategy per step: Steps with 2+ sections (Client, Discovery) get underline tabs + accordion groups. Steps with only 1-2 groups (Deal Info, Schedule) use accordions alone without tabs. The pattern adapts naturally to each step's content volume.
