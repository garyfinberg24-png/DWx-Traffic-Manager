Tab Strategy Per Step

Step Layout Tabs / Accordions
1. Service Grid cards (no change) None needed — card selection grid works well
2. Client Tabs 3 tabs: Request Context | Company Details | Primary Contact
3. Discovery Tabs (dynamic per service) Tabs = service sections (e.g., SPFx: Project Scope | Functional Reqs | Tech Env)
Tabs auto-generated from ServiceRequirementsConfig.sections[]
4. Deal Info Accordions 2 accordions: Deal Qualification (expanded) | Additional Context (collapsed)
5. Schedule Accordions 2 accordions: Meeting Options (expanded) | Additional Notes (collapsed)
6. Review Accordions 3 accordions: Request Overview | Deal Info | Schedule & Ownership (all expanded)
