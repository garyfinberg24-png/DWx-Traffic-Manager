Collapse Toggle Behaviour

  • Expanded (default): Full hero with title, subtitle, stats, search, quick-link cards. ~200px tall.
  • Collapsed: Thin strip (~56px) with just the title + inline stat badges. Quick links and search hidden.
  • Toggle: Small chevron button centered at bottom of hero. Rotates 180° when collapsed.
  • Animation: Smooth 350ms slide transition using CSS max-height + padding.
  • Persistence: localStorage key per page (e.g. dwx-hero-collapsed-my-requests).
  • Global default: "Always start minimised" personal setting (stored in localStorage), togglable from user avatar menu.
  • Reset: Without the global setting, heroes always start expanded on page load (fresh session feel).
